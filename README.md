# saffronspoon

Static catering website for saffron & spoon.

## Free hosting with GitHub Pages

1. Create a public GitHub repository named `saffronspoon`.
2. Push this project to its `main` branch.
3. Open **Settings > Pages** and select **GitHub Actions** as the source.
4. The workflow will publish the site at `https://YOUR-USERNAME.github.io/saffronspoon/`.

Add the provided Zelle image as `zelle-qr.png` beside `index.html` before publishing.
